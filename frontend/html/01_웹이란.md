# 웹이란?

- 웹(Web)의 정식 명칭: World Wide Web
- 인터넷의 응용 계층에서 작동

# 웹이 왜 생겼냐?

- 1989년, 유럽의 입자 물리 연구소의 팀 버너스리에 의해 개발
- 당시에 논문과 데이터가 컴퓨터마다 다 다른 운영체제 및 워드프로세서를 사용해서 데이터 만듦
- 팀 버너스리가 웹을 만듦
- 마크업 언어(Markup Language)를 제안함
- 통신 규약 (HTTP)
- 식별자 (URI)

# 인터넷과 웹

## 인터넷이란?

하드웨어(광케이블, 라우터, 스위치 등)로 연결이 된 거대한 통신망 그 자체

## 웹이란?

인터넷을 사용하는 서비스 중 하나

> 인터넷을 사용하는 서비스
>
> - SMTP(메일 전송), FTP(파일 전송) 등

# 웹이 기존 데이터 처리 방식과 다른 점

## 과거

선형적 데이터 구조를 가짐
: 사전과 같이 처음부터 순차적으로 스캔하고 읽어야 함

## 현재

하이퍼텍스트
: 노드(각각의 정보 단위)와 이를 연결하는 링크의 네트워크로 구성된 데이터베이스 모델
텍스트로 링크에 접속

하이퍼미디어
: 유튜브와 같이 미디어로 링크에 접속

# 클라이언트-서버

## 클라이언트

크롬에서 깃허브라고 쳐서 들어가는 순간
클라이언트가 서버에게 요청
깃허브 메인 페이지 데이터 쓰겠다고 요구

## 서버

클라이언트에게 응답
메인 페이지의 데이터 전달
데이터베이스에 없는 내용은 못 줌

# 웹을 지탱하는 3대 핵심 기술

URI(모든 형태의 문자열), URL(위치), URN(도메인, 이름)

HTTP, HTTPS
HTTP: 클라이언트와 서버가 주고받는 데이터가 암호화되지 않음 → 보안 취약점 문제
HTTPS: HTTP의 문제점을 해결한 것

# HTML

Hypertext Markup Language
마크업 언어 == 태그

index.html이란 데이터가 브라우저에게 전달이 되면, 얘는 메모리 내에서 동적 객체로 변환이 됨

브라우저 내부에서 일어나는 일
HTML 파서(Parser, 읽는 역할)
DOM 트리: 웹페이지의 HTML 문서를 브라우저가 이해할 수 있게 계층 구조로 변환 (≒ 설계도)
뿌리: 트리의 가장 꼭대기 (전체 내용)
가지: 태그
잎: 태그 안 속성

클라이언트 -> 서버에게 데이터 요구
서버 -> 클라이언트에게 데이터 전달
브라우저는 데이터를 그려야 함
but 텍스트 파일(HTML)뿐 그래서 구조를 만들어야 한다(DOM 트리)
DOM 트리(관계성 부여하는 도구)가 있어야 JS 기능 부여 가능
